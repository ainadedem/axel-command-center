# Make the AXEL recreation prompt downloadable

The full rebuild prompt already exists in the project files at `docs/axel-recreation-prompt.md` (about 59,000 characters). Nothing about it changes.

## What happens

- Place an identical copy in your downloadable files, named `axel-recreation-prompt.md`, so it shows up in the files view and can be opened, copied or downloaded directly.
- The original stays where it is, so the two never drift apart unless the prompt is regenerated.

## Notes

No application code, design or data is touched by this.
